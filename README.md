## 1. Аннотация программного продукта

Данный репозиторий содержит исходный код десктопного приложения, реализующего классическую игру «Крестики-нолики» для двух игроков. Программный продукт разработан на платформе .NET 8 с использованием объектно-ориентированного языка программирования C# и технологии построения графического интерфейса Windows Forms. Целью проекта является практическая реализация игровой логики на основе конечного автомата, построение интерактивного пользовательского интерфейса, а также применение принципов многоуровневой архитектуры (Layered Architecture) для обеспечения жёсткого разделения бизнес-логики и слоя представления.

## 2. Правила игры и математическая модель

Игра ведётся на поле размером $3 \times 3$ клетки. Два игрока поочерёдно ставят свои символы — **X** и **O**. Победителем считается тот, кто первым выстраивает три своих символа в ряд: по горизонтали, вертикали или диагонали. Если все 9 клеток заняты и победитель не определён — фиксируется ничья.

Общее число возможных состояний поля ограничено сверху числом размещений с повторениями:

$$N = 3^9 = 19\,683$$

где основание $3$ соответствует трём возможным значениям каждой клетки (`X`, `O`, `Empty`), а показатель $9$ — количеству клеток поля. Фактическое число достижимых позиций меньше ввиду ограничений чередования ходов.

Алгоритм определения победителя проверяет $8$ линий: $3$ строки, $3$ столбца и $2$ диагонали. Сложность проверки — $O(1)$ (фиксированное число итераций).

## 3. Архитектурные решения и структура проекта

Проект разделён на три независимые сборки в соответствии с принципами SOLID:

```
TicTacToe.sln
├── TicTacToe.Logic/       — слой предметной области (net8.0)
│   ├── Board.cs           — игровое поле 3×3, ходы, проверка победителя
│   ├── GameEngine.cs      — управление партией, смена игроков, счёт
│   ├── Player.cs          — модель игрока (имя, символ, счёт побед)
│   ├── CellValue.cs       — перечисление: Empty / X / O
│   └── GameResults.cs     — перечисление результатов партии
│
├── TicTacToe/             — слой представления (net8.0-windows, WinForms)
│   ├── Program.cs         — точка входа
│   ├── MainMenuForm       — главное меню
│   ├── PlayerSetupForm    — настройка имён и символов игроков
│   └── GameForm           — игровое поле, анимация, управление UI
│
└── TicTacToe.Tests/       — модульные тесты (net8.0, xUnit)
    ├── BoardTests.cs      — тесты игрового поля
    └── GameEngineTests.cs — тесты движка игры
```

**TicTacToe.Logic** инкапсулирует всю игровую логику и не имеет зависимостей от графической подсистемы. **TicTacToe** отвечает исключительно за рендеринг, обработку пользовательского ввода и управление формами.

## 4. Модульное тестирование

Верификация алгоритмов проведена с использованием фреймворка **xUnit**. Набор тестов спроектирован по паттерну AAA (Arrange — Act — Assert) и покрывает следующие сценарии:

- Корректность хода: запись символа в клетку, отказ при занятой клетке, выброс исключения при выходе за границы поля.
- Определение победителя: все $3$ строки, $3$ столбца, $2$ диагонали, отсутствие победителя.
- Определение ничьей: полное заполнение поля без победной линии.
- Управление партией: смена текущего игрока, блокировка ходов после окончания игры, сброс поля, сохранение и сброс счёта.
- Валидация входных данных: пустое имя игрока, символ `Empty`, одинаковые символы у обоих игроков, `null`-аргументы.

Для измерения покрытия используется **Coverlet** с генерацией HTML-отчёта через **ReportGenerator**.

Запуск тестов с покрытием:

```bash
dotnet test TicTacToe.Tests/TicTacToe.Tests.csproj --collect:"XPlat Code Coverage"
reportgenerator -reports:"TicTacToe.Tests/TestResults/**/coverage.cobertura.xml" -targetdir:"TicTacToe.Tests/coverage" -reporttypes:Html
```

## 5. Инструкция по сборке и запуску

Для компиляции и запуска необходима платформа **.NET 8 SDK** и операционная система **Windows** (требование Windows Forms).

**Порядок запуска через Visual Studio:**

1. Клонировать репозиторий в локальную файловую систему.
2. Открыть файл решения `TicTacToe.slnx` в Visual Studio 2022.
3. Установить проект `TicTacToe` в качестве загружаемого по умолчанию.
4. Выполнить сборку решения (`F6`).
5. Запустить приложение (`F5`).

**Порядок запуска через терминал:**

```bash
git clone <url>
cd TicTacToe
dotnet run --project TicTacToe/TicTacToe.csproj
```

Для запуска тестов:

```bash
dotnet test TicTacToe.Tests/TicTacToe.Tests.csproj
```
